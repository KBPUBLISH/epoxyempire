# epoxyempire

The Epoxy Empire investor pitch deck, published as a static website by Kingdom Builders Publishing Inc.

## Files

- `index.html` - the animated pitch deck. It is a single self-contained page: no build step, no dependencies.
- `epoxy-empire-pitch-deck.pdf` - the same deck as a PDF.
- `netlify.toml` - Netlify settings: publish the repository root as-is, and ask search engines not to index the site.

## Hosting

The site is meant to be hosted on Netlify, connected to this repository. Netlify publishes whatever is on the `main` branch, so every change pushed to `main` goes live automatically.

To preview locally, open `index.html` in a browser.
